# 🤖 AI Test Assistant (API Test Failure Analyzer)

An AI-powered tool that analyzes API test failures and provides intelligent insights, possible root causes, and suggested fixes.

## 🚀 Project Overview

This project helps QA engineers and developers quickly understand test failures by using LLMs (via Ollama) to analyze error logs.

Instead of manually debugging logs, the AI provides:
- Root cause analysis
- Suggested fixes
- Debugging insights

---

## 🧠 Features

- 🔍 Analyze API test failures
- 🤖 LLM-powered error explanation (Ollama - Llama3/Phi3)
- ⚡ FastAPI backend for API access
- 🧪 Integration with Robot Framework logs
- 📄 Clean and structured responses

---

## 🏗️ Tech Stack

- Python
- FastAPI
- Ollama (LLM)
- Robot Framework
- JSON / REST APIs
